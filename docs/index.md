# mailadmin documentation

mailadmin is a server-rendered administration panel for configuring and monitoring an existing mail stack. It separates Server Admin credentials from mailbox accounts and scopes organization data to each tenant.

## Start here

- [Install mailadmin](installation.md)
- [Configure the server](configuration.md)
- [Use the browser panel](admin.md)
- [Use the CLI and TUI](cli.md)
- [API reference](api.md)
- [Security model](security.md)
- [Integrations](integrations.md)
- [Contribute](development.md)

Supported build targets are Linux and FreeBSD on amd64 and arm64. mailadmin is not a webmail client and does not replace Postfix, Dovecot, or other mail services.
